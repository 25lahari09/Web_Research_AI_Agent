# Web Research AI Agent

An AI-powered web research project built with Python, integrating the Tavily Search API to support web information retrieval and AI-assisted research.

## Project Overview

The Web Research AI Agent explores how external web search capabilities can be integrated into an AI application.

The project is currently under development and serves as a practical implementation of Python programming, API integration, and AI application development.

- **Tavily API** — Web search integration

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/25lahari09/Web_Research_AI_Agent.git
cd Web_Research_AI_Agent
```

**2. Create a virtual environment**

```bash
python -m venv venv
```

**3. Activate the virtual environment (Windows PowerShell)**

```powershell
.\venv\Scripts\Activate.ps1
```

**4. Install dependencies**

Install the Python packages required by the application. A `requirements.txt` file will be added as the project is finalized.

**5. Configure environment variables**

Create a `.env` file in the project root and configure the API credentials required by the application.

For Tavily integration:

```env
TAVILY_API_KEY=your_tavily_api_key
```

Never commit real API keys to GitHub.
